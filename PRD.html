个人网站 产品需求文档（PRD）

一、产品概述与目标

1.1 项目背景

作为物联网工程专业的学生，需要向老师、同学和未来的招聘方展示个人能力与学习成果。目前缺少一个集中展示个人信息、技能、项目和博客内容的个人网站。

1.2 产品目标

开发一个深色星空主题的个人展示网站，实现：

  1. 展示个人介绍、教育背景与技能
  1. 集中展示开发过的项目（AI翻译助手、天气助手、电商图片下载插件等）
  1. 支持博客文章展示
  1. 提供联系方式入口
  1. 适配电脑、平板、手机等多端设备

1.3 目标用户

  • 老师与评审：查看实践成果与开发能力
  • 同学：交流学习、查看项目经验
  • 潜在招聘方：了解个人技能与作品

三、界面设计要求

3.1 视觉风格

  • 深色主题：背景 #080F1A，文字 #E6EAF2，强调色可配置（紫色渐变）
  • 星空背景：Canvas 粒子系统，缓慢闪烁 + 视差效果；移动端降低粒子数
  • 简洁现代：留白充足、层级清晰、圆角 12-16px、统一缓动动画

3.2 响应式

  • 手机（<640px）：单列布局
  • 平板（640-1024px）：两列布局
  • 桌面（>1024px）：三列布局
  • 内容最大宽度 1200px

3.3 交互

  • 导航吸顶毛玻璃效果
  • 滚动进入视口时淡入上移动画
  • 卡片 hover 轻微上浮 + 阴影变化
  • 星空粒子尊重 prefers-reduced-motion

四、技术栈建议

层选型说明
框架React 18 + TypeScript组件化、类型安全
构建Vite快速启动与构建
样式Tailwind CSS / CSS 变量快速统一风格
部署Vercel / Cloudflare Pages免费托管静态站点

五、非功能性需求

5.1 性能

  • 首屏加载 < 3s
  • 移动端星空动画帧率 ≥ 50fps
  • 无多余依赖，产物体积可控

5.2 兼容性

  • 支持 Chrome / Edge / Firefox
  • 375px 宽度下无横向滚动

5.3 安全与隐私

  • 纯前端实现，不收集用户数据
  • 表单仅做前端校验演示

六、验收标准（MVP）

  1. 打开页面可见深色星空背景与 Hero 区
  1. 导航可锚点跳转，移动端汉堡菜单可展开
  1. 个人介绍、技能、项目三个板块内容完整
  1. 375px 手机宽度下布局正常、无横向滚动
  1. 无控制台报错
