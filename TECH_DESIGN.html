个人网站 技术设计文档（TECH_DESIGN.md）

一、技术栈选择

层选型版本选择理由
前端框架React18组件化开发，生态成熟，适合单页站点
开发语言TypeScript5.x类型安全，减少运行时错误
构建工具Vite5.x启动快、构建快，开箱即用
路由React Router6.x单页应用路由管理
样式原生 CSS + CSS 变量—深色主题统一管理，无需引入重型 UI 库
星空背景Canvas 原生绘制—粒子闪烁 + 视差，性能可控
部署Vercel / Cloudflare Pages—免费托管，支持静态站点，全球 CDN

说明：不引入 Tailwind 等额外依赖，使用 CSS 变量统一主题，保证项目轻量、可直接运行。

四、关键技术点

4.1 星空背景（Canvas 粒子）

  • 使用 requestAnimationFrame 循环绘制粒子
  • 每个粒子：随机位置、大小、闪烁速度，透明度正弦变化模拟闪烁
  • 鼠标移动时粒子产生轻微视差偏移
  • 移动端（视口 < 768px）粒子数量减半
  • 尊重 prefers-reduced-motion，用户偏好减弱动效时不启动动画

4.2 响应式布局

  • 使用 CSS Grid + repeat(auto-fit, minmax()) 实现卡片自适应
  • 断点：<640px 单列 / 640-1024px 两列 / >1024px 三列
  • 导航在移动端折叠为汉堡菜单

4.3 滚动动画

  • IntersectionObserver 监听元素进入视口，触发淡入上移

五、开发与运行

`bash

npm install # 安装依赖

npm run dev # 本地开发（默认 http://localhost:5173）

npm run build # 构建生产版本（输出 dist/）

npm run preview # 本地预览构建产物

`

六、部署方案

  1. 代码推送到 GitHub 仓库
  1. Vercel / Cloudflare Pages 导入该仓库
  1. 框架预设选择 Vite，构建命令 npm run build，输出目录 dist
  1. 部署完成后获得免费域名 xxx.pages.dev 或 xxx.vercel.app
